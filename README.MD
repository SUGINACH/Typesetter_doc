## 🚀 הפעלת GitHub Wiki

כדי להפוך את תיקיית `wiki/` לויקי רשמי של הריפו ב-GitHub:

1. בקר בכתובת: https://github.com/SUGINACH/Typesetter_doc/wiki
2. לחץ על **"Create the first page"**
3. הזן כל תוכן (למשל "init") ולחץ **Save**
4. לאחר מכן ניתן יהיה לשכפל את ויקי ה-GitHub (`git clone https://github.com/SUGINACH/Typesetter_doc.wiki.git`) ולהעתיק אליו את קבצי ה-markdown מתיקיית `wiki/`.
