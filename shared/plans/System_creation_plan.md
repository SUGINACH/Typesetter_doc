## פרק א: פילוסופיית העימוד התורני והגדרת המערכת

### 1.1 מהות העימוד התורני המסורתי
ספרות תורנית (ספרי שו"ת, חידושי ש"ס, ספרי הלכה, מפרשים ודרוש) מתאפיינת במסורת דפוס ייחודית שהתגבשה במשך מאות שנים (דפוסי ונציה, וילנא, ליוורנו, פיוטרקוב וירושלים). בשונה מספרות כללית או עימוד עיתונאי:
- **קדושת הדף והרציפות**: כל עמוד הוא יחידה ארכיטקטונית סגורה. הדף נתפס כמשטח אחיד, מאוזן וסימטרי.
- **איסור שבירה שרירותית**: אין להשאיר שורות קטועות, מילים בודדות ("יתומים") או טורים בגבהים שונים ללא סיבה מבנית.
- **פתיחים מודגשים ("חלון פתיח")**: כל פסקה פותחת במילה ראשונה מוגדלת ומודגשת, כאשר בגוף טקסט רב-שורתי המילה הראשונה "יושבת בתוך חלון" שנוצר בשתי השורות הראשונות.
- **איזון טורים קפדני**: כאשר פרק מסתיים באמצע עמוד, שני הטורים חייבים להסתיים **באותו קו גובה אנכי בדיוק**. אסור בתכלית האיסור שהטור הימני ימשיך עד תחתית הדף בעוד הטור השמאלי יישאר ריק או קצר.
- **היררכיה ברורה**: חלוקה בין גוף הטקסט, כותרות ראשיות (שערים, סימנים), כותרות פנימיות (ענפים, סעיפים) והערות שוליים צדדיות ("הגהות / ציונים").

### 1.2 מטרת המערכת והגדרת המוצר
מערכת זו היא **מנוע עימוד והטלת עמודים (Desktop/Browser Typesetting Engine)** הפועל בתוך קובץ HTML יחיד ועצמאי (Self-contained). המערכת מקבלת טקסט גולמי ומייצרת בזמן אמת עמודי A4 תקניים (210 מ"מ על 297 מ"מ) מוכנים להדפסה (Print-Ready) ולייצוא PDF וילנאי מובהק.

### 2.1 מידות A4 וגבולות הדפסה
- **רוחב הדף**: $210\text{mm} \approx 793.7\text{px}$ (ב-96 DPI).
- **גובה הדף**: $297\text{mm} \approx 1122.5\text{px}$ (ב-96 DPI).
- **שולי העמוד (Page Padding)**: $15\text{mm} \approx 56.7\text{px}$ מכל ארבעת הצדדים.
- **גובה נטו בתוך השוליים**: $1122.5 - (2 \times 56.7) = 1009.1\text{px}$.
- **רוחב נטו בתוך השוליים**: $793.7 - (2 \times 56.7) = 680.3\text{px}$.

### 2.2 מבנה השכבות האנכי (Vertical Layout Pipeline)
החלל הפנימי של העמוד מחולק ל-3 אזורים קבועים:
1. **כותרת עליונה רצה (`.top-header-grid`)**: גובה קבוע $24\text{px}$.
2. **מרווח נשימה עליון**: מרווח של $16\text{px}$ בדיוק בין הכותרת העליונה לגוף הטקסט.
3. **מרחב גוף הטקסט (`.page-body-flow`)**:
   - בעמוד רגיל: גובה זמין מקסימלי $H_{\text{max}} = 1009.1 - (24 + 16 + 16 + 24) \approx 929\text{px}$ (בפועל מוגבל ל-**$900\text{px}$** למניעת חיתוך).
   - בעמוד הפותח ב"כותרת 2" (סימן חדש): תופס את שני השלישים התחתונים בלבד ($H_{\text{max}} \approx 570\text{px}$).
4. **מרווח נשימה תחתון**: מרווח של $16\text{px}$ בדיוק בין גוף הטקסט לכותרת התחתונה (**סימטרי לחלוטין למרווח העליון**).
5. **כותרת תחתונה ומספר עמוד (`.page-number-footer`)**: גובה קבוע $24\text{px}$, מציג מספר עמוד באותיות עבריות (גימטריה).

### 2.3 גריד 7 העמודות הסימטרי (CSS Grid System)
כל שורת תוכן דו-טורית (`.block-2col`) וכותרת עליונה (`.top-header-grid`) מבוססות על פריסת Grid בעלת 7 עמודות:
$$\text{Columns} = [W_{\text{margin}}, W_{\text{gap}}, W_{\text{col}}, W_{\text{gutter}}, W_{\text{col}}, W_{\text{gap}}, W_{\text{margin}}]$$
- עמודה 1 (`right-margin`): הערות שוליים עבור הטור הימני ($7.5\% \approx 51\text{px}$).
- עמודה 2: רווח ביניים ימני ($2.0\% \approx 13.6\text{px}$).
- עמודה 3 (`right-col`): טור טקסט ראשי ימני ($39.5\% \approx 268.7\text{px}$).
- עמודה 4: גאטר/רווח מרכזי ($2.0\% \approx 13.6\text{px}$).
- עמודה 5 (`left-col`): טור טקסט ראשי שמאלי ($39.5\% \approx 268.7\text{px}$).
- עמודה 6: רווח ביניים שמאלי ($2.0\% \approx 13.6\text{px}$).
- עמודה 7 (`left-margin`): הערות שוליים עבור הטור השמאלי ($7.5\% \approx 51\text{px}$).

סה"כ: $7.5 + 2.0 + 39.5 + 2.0 + 39.5 + 2.0 + 7.5 = 100\%$.

### 3.1 כלל הזהב של כותרת 2 (סימן חדש בשליש עמוד)
כאשר מופיעה "כותרת 2":
1. היא פותחת עמוד חדש תמיד.
2. בראש ה-`page-body-flow` מוצב ספייסר עליון (`.h2-page-spacer`) בגובה של **שליש מדויק משטח הטקסט** ($\approx 290\text{px}$).
3. תחת הספייסר מופיעה כותרת הסימן (`.title-level-2-standalone`).
4. גוף הטקסט מתחיל מיד תחת הכותרת וזורם מטה לתוך שני השלישים הנותרים של העמוד ($560\text{px}$–$570\text{px}$).
5. **איסור מתיחה**: אם הסימן קצר (למשל פסקה אחת בלבד), הטקסט מאוזן בין הטורים מיד תחת הכותרת, ושאר העמוד כלפי מטה נשאר ריק. אין למתוח את הפסקאות לתחתית הדף (`justify-content: flex-start`).

### 3.2 כלל הרציפות של כותרת 3 (ענף חוצה טורים)
כאשר מופיעה "כותרת 3":
1. **היא אינה פותחת עמוד חדש בשום אופן** (אלא אם כן נותרו פחות מ-$90\text{px}$ בתחתית העמוד שאינם מאפשרים להציג את הכותרת ולפחות 2 שורות טקסט).
2. הטקסט שקדם לכותרת 3 **חייב להתאזן במלואו** בשני הטורים שלפניה.
3. כותרת 3 נפרסת על פני רוחב שני הטורים והגאטר (עמודות 3 עד 5 בגריד: `grid-column: 3 / 6`).
4. הטקסט שלאחר כותרת 3 מתחיל מיד תחתיה כבלוק דו-טורי חדש **באותו העמוד**.

## פרק ד: מנגנון הפתיח – "חלון מילה ראשונה" (Drop-Caps Logic)

בספרי קודש, המילה הראשונה של כל פסקה מודפסת בגופן גדול ומפואר ("אותיות רבתי / פתיח"). המערכת מיישמת לוגיקה תלת-מצבית מדויקת:

```
[מצב א': פסקה מרובת שורות (>= 2 שורות)]
+--------+------------------------------------+
|        | שורה 1: המשך הטקסט של הפסקה הזורם  |
|  פתיח  +------------------------------------+
| (צף)   | שורה 2: לצד החלון ומתחתיו          |
+--------+------------------------------------+
| שורה 3: הטקסט ממשיך לרוחב הטור המלא...       |
+---------------------------------------------+

[מצב ב': פסקה בת שורה אחת בלבד]
+---------------------------------------------+
| פתיח (אינליין) והמשך המשפט באותה שורה       |
+---------------------------------------------+

[מצב ג': פסקת המשך מטור קודם / עמוד קודם]
+---------------------------------------------+
| המשך הפסקה בגופן גוף רגיל ללא פתיח כלל...   |
+---------------------------------------------+
```

### 4.1 אלגוריתם סיווג הפתיח
עבור כל פסקה בטקסט:
1. **בדיקת המשכיות (`isContinuation`)**:
   - אם הפסקה היא המשך של פסקה שנחצתה בטור קודם או בעמוד קודם $\rightarrow$ **אין פתיח כלל**. כל המילים מוצגות בגופן גוף רגיל.
2. **מדידת אורך הפסקה ב-DOM המדידה**:
   - הפסקה נמדדת בתוך אלמנט מדידה בלתי-נראה בעל רוחב טור מדויק.
   - אם גובה הפסקה $\le 1.45 \times \text{SingleLineHeight}$ (הפסקה מחזיקה שורה אחת בלבד):
     $$\text{HTML} = \text{`<span class="first-word-inline">${w_0}</span> ${w_1...w_n}`}$$
     - עיצוב `.first-word-inline`: מקבל גופן וגודל של מילה ראשונה, אך **`display: inline; float: none;`**. הדבר מונע השארת חלל ריק מתחת לפסקה קצרה ומבטיח שהפסקה הבאה לא תיתקע בתוך החלון.
   - אם גובה הפסקה $> 1.45 \times \text{SingleLineHeight}$ (הפסקה מחזיקה 2 שורות ומעלה):
     $$\text{HTML} = \text{`<span class="first-word-window">${w_0}</span> ${w_1...w_n}`}$$
     - עיצוב `.first-word-window`: מקבל `float: right; height: 1.15em; line-height: 0.82; margin-left: 6px; margin-bottom: 2px; display: block;`. שתי השורות הראשונות של הפסקה עוטפות את המילה הראשונה מימין, ויוצרות חלון פתיח מושלם.

## פרק ה: אלגוריתם איזון הטורים התלת-שלבי (The 3-Tier Column Balancing Engine)

איזון הטורים הוא הליבה של העימוד התורני. בסיום פרק, לפני כותרת 3, או בסוף מסמך, שני הטורים חייבים להסתיים באותו קו אופקי.

```
                     +---------------------------+
                     | אוסף יחידות טקסט לאיזון   |
                     +-------------+-------------+
                                   |
                                   v
             +-----------------------------------------------+
             | שלב 1: חיפוש נקודת חלוקה בין פסקאות שלמות     |
             | האם קיים פיצול שבו R >= L וההפרש <= שורה (24px)?|
             +---------------------+-------------------------+
                                   |
                     +-------------+-------------+
                     | כן                        | לא
                     v                           v
         +-----------------------+   +------------------------------------+
         | העברת פסקאות שלמות    |   | שלב 2: פירוק פסקת הגבול לשורות     |
         | ללא חיתוך פסקה        |   | מעומדות והעברת שורות שלמות מימין   |
         +-----------+-----------+   | לשמאל עד שההפרש מינימלי (R >= L)   |
                     |               +-----------------+------------------+
                     |                                 |
                     +----------------+----------------+
                                      |
                                      v
         +------------------------------------------------------------+
         | שלב 3: האם נותר הפרש של שורה בודדת (3px < Diff <= 25px)?   |
         +----------------------------+-------------------------------+
                                      |
                     +----------------+----------------+
                     | כן                              | לא (מאוזן בדיוק)
                     v                                 v
         +-----------------------------+   +--------------------------+
         | מיקרו-כוונון בטור שמאל:     |   | סיום עימוד הבלוק המאוזן  |
         | הגדלת Line-Height ב-0.03    |   +--------------------------+
         | והגדלת Margin-Bottom קלות   |
         +-----------------------------+
```

### 5.1 בניית היחידות האטומיות (Atomic Units Construction)
לפני חלוקה לטורים, כל הפסקאות במקטע מפורקות באמצעות DOM-Scanner לשורות פיזיות:
1. טקסט הפסקה נמדד ברוחב הטור המדויק שנמדד מהדפדפן (`getExactColumnWidth()`).
2. כל מילה נעטפת בספאן `<span class="w">`.
3. באמצעות קריאת `span.offsetTop`, המילים מקובצות למערכי שורות מדויקים:
   $$\text{Paragraph} \rightarrow [\text{Line}_0 = [w_0, w_1...], \text{Line}_1 = [w_k, w_{k+1}...], ..., \text{Line}_m = [...]]$$
4. נוצרת רשימה שטוחה של יחידות אטומיות (`atomicUnits`), כאשר:
   - כותרת פנימית (H4–H6) = יחידה אחת בלתי-ניתנת לחלוקה עם גובה מדויק.
   - שורת פסקה = יחידה אטומית אחת עם גובה שורה ($20\text{px}$) ומערך המילים שלה.

### 5.2 שלב 1: העברת פסקאות שלמות (Whole Paragraph Transfer)
- המנוע בוחן את כל נקודות המעבר בין פסקאות או כותרות ($s$).
- עבור כל נקודה מחושב הגובה של הטור הימני ($H_R$) והטור השמאלי ($H_L$).
- תנאי הצלחה של שלב 1:
  $$H_R \ge H_L \quad \text{AND} \quad (H_R - H_L) \le \text{LineHeight} \times 1.1 \ (\approx 24\text{px})$$
- אם נמצא פיצול כזה, **הפסקאות אינן נחתכות כלל**. פסקאות $0 \dots s-1$ מוצבות בימין, ופסקאות $s \dots N$ מוצבות בשמאל.

### 5.3 שלב 2: העברת שורות שלמות מתוך פסקה חצויה (Whole Line Transfer)
- אם שלב 1 לא השיג איזון בטווח שורה בודדת, המנוע בוחן חלוקה בכל שורה ושורה ($s \in [1 \dots \text{totalUnits}]$).
- נבחרת נקודת הפיצול $s$ הממזערת את ההפרש:
  $$\min (H_R - H_L) \quad \text{subject to} \quad H_R \ge H_L$$
- **כלל חיתוך הפסקה**:
  - חלקה הראשון של הפסקה בטור הימני מקבל מחלקה `class="p-cut"`.
  - עיצוב `p-cut`: `text-align: justify; text-align-last: justify;`. השורה האחרונה של המקטע הימני נמתחת מקצה לקצה של הטור, כך שאין שום רווח ריק או מילה בודדת קטועה.
  - חלקה השני של הפסקה בטור השמאלי מתחיל ללא פתיח ומסתיים כפסקה רגילה `class="p-end"` (`text-align-last: center;`).

### 5.4 שלב 3: מיקרו-כוונון אנכי (Sub-line Vertical Justification)
אם לאחר שלב 2 נותר הפרש של שורה בודדת ($3\text{px} < H_R - H_L \le 25\text{px}$) הנובע ממספר שורות אי-זוגי:
1. מחושבת תוספת גובה שורה מזערית עבור פסקאות הטור השמאלי:
   $$\Delta \text{lineHeight} = \min\left(0.08, \frac{H_R - H_L}{H_L \times 2.2}\right)$$
2. ה-`lineHeight` של פסקאות הטור השמאלי מוגדל קלות (למשל מ-1.34 ל-1.37).
3. אם נותר פער של פיקסלים ספורים, הוא מחולק שווה בשווה ל-`margin-bottom` בין פסקאות הטור השמאלי.
4. **תוצאה**: קו הסיום התחתון של הטור השמאלי מיושר בדיוק של פיקסל לקו הסיום של הטור הימני.

## פרק ו: מנגנון תוכן העניינים (TOC) הכללי והמפורט ומניעת גלישה

### 6.1 שורש כשל הגלישה בתוכן העניינים
במערכות פרימיטיביות, חלוקת עמודי תוכן העניינים מבוצעת על בסיס "ספירת שורות שרירותית" (למשל 20 שורות לעמוד). זוהי שגיאה אדריכלית חמורה, מכיוון ש:
- כותרת ארוכה תופסת 2–3 שורות פיזיות.
- רמות שונות מקבלות גופנים וגדלים שונים.
- בלוקים מקובצים (כותרות 4–6 ברצף עם קווי הפרדה `|`) תופסים גובה משתנה של 30 עד 120 פיקסלים.

### 6.2 האלגוריתם הדינמי לחלוקת עמודי תוכן עניינים (Dynamic TOC Pagination)
המנוע מיישם צבירת גובה פיקסלים מדויקת:
1. נוצרת רשימת פריטי תוכן מעובדת (`buildStructuredTOC`): פריטים ראשיים (כותרות 1–3) נשמרים כשורות בודדות עם מובילי נקודות (`toc-dots`), ופריטי משנה מקובצים לבלוק רציף (`toc-grouped-block`).
2. עבור כל עמוד תוכן עניינים:
   - בעמוד הראשון של התוכן מוקצה גובה לכותרת הראשית "תוכן העניינים". הגובה הזמין הוא $H_{\text{avail}} \approx 820\text{px}$.
   - בעמודי תוכן עוקבים הגובה הזמין הוא $H_{\text{avail}} \approx 890\text{px}$.
3. פריטי התוכן מוכנסים לעמוד בזה אחר זה ונמדדים ב-DOM חי.
4. ברגע שהוספת הפריט הבא תגרום לגובה הכולל לעלות על $H_{\text{avail}}$:
   - הפריט אינו מוכנס לעמוד הנוכחי.
   - העמוד הנוכחי נחתם ונסגר.
   - נפתח עמוד תוכן עניינים חדש עם כותרות עליונות ומספר עמוד רץ, והפריט נכנס כראשון בעמוד החדש.
5. **ערבות אפס גלישה**: טקסט תוכן העניינים לעולם אינו מגיע למספר העמוד ולעולם אינו גולש מחוץ לדף.

### 6.3 סנכרון כותרות עליונות בעמודי תוכן
עמודי תוכן העניינים (הכללי והמפורט) כוללים כותרת עליונה רצה (`.top-header-grid`) התואמת ב-100% את ההגדרות שנבחרו בסרגל השליטה (גופנים, גדלים, עיטור מרכזי ויישור).

## פרק ח: ארכיטקטורת נתונים, פייפליין העימוד וסנכרון תצוגה

```
                      [ Raw Text Input ]
                              │
                              ▼
                 [ Step 1: Metadata Extraction ]
                  - שם הספר, מחבר, שנה, נושא
                              │
                              ▼
                   [ Step 2: Tokenization ]
                  - פירוק לטוקנים: H0-H7, P, Notes
                              │
                              ▼
                 [ Step 3: Section Partition ]
                  - פיצול למקטעי על: שער, הקדמה, סימנים
                              │
                              ▼
                [ Step 4: Virtual DOM Scanner ]
                  - מדידת רוחב טור מדויק
                  - פירוק פסקאות למערכי שורות אטומיות
                              │
                              ▼
             [ Step 5: Master Pagination Pipeline ]
             ┌────────────────┼────────────────┐
             ▼                ▼                ▼
       [Main Shaar]     [TOC Engine]    [Body Engine]
      - שער ראשי 1-3   - כללי ומפורט   - עמודי H2 (שליש)
                       - מדידת גובה     - איזון טורים
                                        - חלוקת שורות
                              │
                              ▼
               [ Step 6: Post-Layout Resolver ]
                  - עדכון גימטריה בתוכני עניינים
                  - הצמדת הערות שוליים בפיקסלים
                              │
                              ▼
                  [ Interactive Sync Engine ]
                  - קליק/חצים בסרגל גוללים לדף
```

### 8.1 אובייקט הנתונים של טוקן (Token Data Structure)
```typescript
interface Token {
  id: number;
  type: 'h0' | 'h1' | 'h2' | 'h3' | 'h4' | 'h5' | 'h6' | 'p';
  level?: number;
  text: string;
  sideNote?: string | null;
  lineIdx: number;
  linesWords?: string[][]; // מערך שורות שכל אחת מכילה מערך מילים
  hasWindow?: boolean;     // האם מקבל חלון פתיח (>= 2 שורות)
  isSingleLine?: boolean;  // האם שורה אחת בלבד (אינליין)
}
```

### 8.2 אובייקט יחידה אטומית (Atomic Unit Structure)
```typescript
interface AtomicUnit {
  type: 'heading' | 'line';
  token: Token;
  h: number;               // גובה פיזי בפיקסלים
  lIdx?: number;           // אינדקס השורה בתוך הפסקה
  totalLines?: number;     // סה"כ שורות בפסקה
  words?: string[];        // מילות השורה
  hasWindow?: boolean;
  isSingleLine?: boolean;
  sideNote?: string | null;
}
```

### 8.3 סנכרון דו-כיווני (Cursor-to-Preview Sync)
- כל אלמנט מעומד בדף מקבל תכונת `data-token-id="${token.id}"`.
- בעת לחיצה על עורך הטקסט או תנועה עם מקשי החצים, המערכת מזהה את השורה הפעילה, מאתרת את ה-`token.id` המתאים ומבצעת גלילה חלקה (`scrollIntoView({ behavior: 'smooth', block: 'center' })`) אל הפסקה או הכותרת המדויקת בתצוגת העמודים.
