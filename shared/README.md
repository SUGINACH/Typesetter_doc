# 🌐 shared

> תיקיית **מסמכים משותפים** — מכילה מסמכים שאינם ספציפיים לגרסה אחת של התוכנה, אלא רלוונטיים לכל הגרסאות. כוללת מחקרים תיאורטיים, תכניות עבודה, השוואות בין-גרסאיות, אוסף פרומטים, ומפרטי תפריט.

---

## 🌐 אודות הפרויקט

ריפו תיעוד של **מערכת עימוד ספרים תורניים** — כלי אינטרנטי לעימוד ספרי קודש לפי כללי הדפוס התורני המסורתי. המערכת פותחה במקביל על ידי שלושה כלי AI (Claude, ChatGPT, z.ai).

📍 **מיקום נוכחי:** `shared`
