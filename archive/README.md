# 📦 archive

> תיקיית **ארכיון היסטורי** — מסמכים ישנים מהשלבים הראשונים של הפרויקט, שלא שויכו לגרסה ספציפית. מייצגת את ההיסטוריה לפני הפיצול לשלוש גרסאות.

---

## 🌐 אודות הפרויקט

ריפו תיעוד של **מערכת עימוד ספרים תורניים** — כלי אינטרנטי לעימוד ספרי קודש לפי כללי הדפוס התורני המסורתי. המערכת פותחה במקביל על ידי שלושה כלי AI (Claude, ChatGPT, z.ai).

📍 **מיקום נוכחי:** `archive`
